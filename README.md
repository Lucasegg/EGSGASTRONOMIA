# EGS Gastronomia

Site institucional responsivo da EGS Gastronomia, desenvolvido para apresentar o chef, estilos de culinária, tipos de eventos e canais de orçamento.

## Publicação

O site utiliza HTML e CSS puros e está preparado para publicação pelo GitHub Pages a partir da branch `main` e da pasta raiz.

A publicação é realizada automaticamente pelo GitHub Actions após alterações na branch `main`.
